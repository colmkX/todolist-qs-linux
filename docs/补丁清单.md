## 1. `titlebar-on-linux` — Linux 上启用自绘标题栏

### 1.1 症状

Linux 上主窗口**没有任何关闭 / 最小化 / 最大化按钮**。

![补丁前](evidence/补丁前-顶部无标题栏.png)

### 1.2 根因（原版应用的真实缺陷）

两个判断在 Linux 上叠加：

```js
// 主进程 background.js —— 非 macOS 一律无边框
const e = "darwin" === process.platform;
new BrowserWindow({ width: 1000, height: 680, frame: e, ... })

// 渲染进程 js/chunk-common.*.js（Vuex store）—— 只给 win32 开自绘标题栏
hasTitleBar: "win32" === process.platform

// App.vue 渲染函数
t.$store.state.ui.hasTitleBar ? e("title-bar") : t._e()
```

| 平台 | 系统标题栏 `frame` | 自绘标题栏 `hasTitleBar` | 结果 |
|---|---|---|---|
| Windows | ❌ | ✅ | 正常 |
| macOS | ✅ | ❌ | 正常 |
| **Linux** | ❌ | ❌ | **两者皆无 → 没有任何窗口按钮** |

作者把主进程的「非 macOS」当成了「Windows」，但渲染进程只认 `win32`。
Linux 版从未发布，所以这个缺陷一直没暴露。

### 1.3 修复

把渲染进程的判断改为「非 macOS」，与主进程语义对齐：

```diff
- hasTitleBar: "win32"===process.platform
+ hasTitleBar: process.platform!="darwin"
```

### 1.4 实现细节

```js
{
  id: 'titlebar-on-linux',
  files: /^\/js\/[^/]*\.js$/,                                  // 用正则，不硬编码文件名哈希
  pattern: /hasTitleBar\s*:\s*"win32"\s*===\s*process\.platform/g,
  replace: () => 'hasTitleBar:process.platform!="darwin"',
}
```

**原始串与替换串均为 26 字节**，因此可以**原地字节替换**：

| | 值 |
|---|---|
| 目标文件 | `/js/chunk-common.<hash>.js`（每次构建哈希都变，故按内容搜索） |
| 文件内偏移 | 60902（3.14.2） |
| asar 绝对偏移 | 267993348 |
| 原串 | `"win32"===process.platform` |
| 新串 | `process.platform!="darwin"` |

原地替换只改这 26 个字节，**asar 头部、所有文件偏移、总长度全部不变**，
随后同步更新头部里该文件的 SHA-256 记录（2 处）。

### 1.5 为什么改 asar 是安全的

`EnableEmbeddedAsarIntegrityValidation` fuse = **disabled**，
且该限制说明指出 Electron 只在 macOS/Windows 上编译该特性 —— Linux 上不校验。
（用 `mcp__rea__inspect_electron_fuses` 实测确认。）

补丁工具还会**先把 asar 头部记录的哈希与实际内容比对**，相符才动刀；
若未来版本对不上，会明确报错而不是盲改。

## 2. 新增补丁的方法

在 `scripts/patch.mjs` 的 `PATCHES` 数组加一条即可，其余流程无需改动：

```js
{
  id: 'some-fix',
  desc: '一句话说明症状与根因',
  files: /^\/js\/[^/]*\.js$/,        // asar 内路径正则
  pattern: /要匹配的原文/g,           // 必须带 g
  replace: (m) => '替换后的文本',     // 可返回不等长文本，引擎会自动重打包
}
```

引擎行为：

1. 按 `files` 正则筛候选文件（跳过 `unpacked` 条目）
2. 逐个用 `pattern` 搜索，命中即停（每个补丁只作用于第一个命中的文件）
3. 替换后若长度不变 → 原地替换；有任何文件变长 → 自动重打包整个 asar
   （重建头部与所有偏移、刷新完整性哈希）
4. 找不到目标 → 明确报错并以非零退出，**不会静默跳过**

`--list` 列出补丁，`--dry-run` 只报告不改盘，`--only <id>` 只跑指定补丁。
